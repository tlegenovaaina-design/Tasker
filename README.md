# Система учета товаров

Это учебный проект для изучения основ сопровождения ПО.

## Что было исправлено в этой версии:
- Изменен IP-адрес сервера в строке подключения на локальный (127.0.0.1).
- Исправлен критический баг: теперь итоговая цена товара не может быть отрицательной.

## Инструкция по запуску
1. Откройте файл проекта в Visual Studio.
2. Нажмите кнопку **Start** (или F5) для компиляции и запуска программы.
3. Убедитесь, что в консоли выводится корректная цена.
